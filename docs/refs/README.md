# Reference images

These frames set the **look**: low-poly toy island, soft lighting, slate HUD panels, cream onboarding screens, ornate dark card frames, rounded type. They were made before spec v2.0, so some **content** in them is out of date. The spec wins. Do not build any of the following.

| Ref | In the image | Build this instead (spec v2.0) |
| --- | --- | --- |
| 01-day-hud | Level and XP bar on the player card | No levels. Player card shows name and avatar; Tugas Hari Ini sits under it |
| 01-day-hud | Plot panel always open bottom-left | Plot panel opens on demand (Tab or tap a plot) |
| 01-day-hud | Minimap bottom-right | No minimap |
| 01-day-hud | Water as a percentage | Water in cm against the target band |
| 01-day-hud | Jetty, boat, shop stall | No jetty or shop. Keep the cottage, plots, canal, gates, longkang, trees |
| 01-day-hud | 4 plots all planted | Season 1 opens Plot 1 only |
| 02-night-hud, 04-night-event-cards | Level bar; water as a percentage | As above |
| 04-night-event-cards | "Satu Peristiwa Berlaku", pick 1 of 3 different cards, % effects | One card a night: Bala (purple frame) with 2–4 response buttons, or Rezeki (green frame) with take or decline. Effects in RM, hours, cm, health. Keep the card frame style, art window and night backdrop |
| 03-onboarding | 4 steps, including "Namakan bendang"; 6 presets | 3 steps: character (4 presets), name, ready. No bendang naming |
| 03-onboarding | Standard Malay text | All text comes from `content/i18n/` (Kedah by default) |
| 03-onboarding | "Selamat datang" screen | Tok Wan's welcome at the cottage, then 3 starter seed cards |
| 05-plot-empty-nav | Left rail with extra items | Left rail: Fon, Kitab, Tetapan only |
| 06-tutorial-controls | Controls list | Add F (phone) and Z (sleep); no skip options |
